## 结果与结论

本轮方案未证明能够稳定提高原有 Day 模型的 Recall。部分 SVOX 开发集 Top1 收益没有稳定转化为外部数据集及 Top5/Top10 收益，现有证据不足以继续投入此路线。

- 阶段一修订版 P0，SVOX dev 共 702 个查询：A 三种子 Top1 命中数为 617/618/622，B 为 622/625/624，C 为 616/617/621。B 相比 A 增加 5/7/2 个 Top1，但 Top5 下降，不能据此认定整体检索泛化改善。
- 阶段二：T0/T2 的 Top1/5/10 为 617/668/676，T1/T3 为 622/667/675；QwenToken 风格方案没有改变对应的 TopK 命中集合。
- GSV 扩展：G1-A 为 621/668/677，G1-B 为 624/666/674，G2-A 为 623/668/676，G2-B 为 624/666/676。扩大源域没有带来稳定补益。
- 外部夜间评估共 13 个模型 × 4 个设置，52 项完成。下表为 Top1 百分比，多种子取均值。
